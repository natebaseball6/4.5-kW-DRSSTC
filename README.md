# DRSSTC-Universal-Driver-2026
Revising Loneocean's UD2.7c to use surface mount technology and to replace retired components. Allows for MIDI modulation via fiber-optic cable. Includes Over Current Detection, Phase Lead, and a Feedback Loop.
