# DRSSTC-Universal-Driver-2026
Revising Loneocean's UD2.7c to use surface mount technology and to replace retired components. Allows for MIDI modulation via fiber-optic cable. Includes Over Current Detection, Phase Lead, and a Feedback Loop.

WORK IN PROGRESS

NOTHING IS FINAL OR EVEN ENTIRELY ACCURATE, INCLUDING BOM AND SCHEMATIC.

BOM may be outdated

The KiCAD project is the most up-to-date part of the project, with every part of the schematic complete save for the gate drive and the logic testing locations.
